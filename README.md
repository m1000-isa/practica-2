# practica-2
1. ¿Qué es una Base de Datos Relacional?
Es un tipo de sistema de almacenamiento que organiza la información en tablas que se conectan entre sí por medio de claves. Se basa en el modelo relacional creado por Edgar F. Codd y se administra usando el lenguaje SQL.
2. ¿Qué es una Tabla?
Es una estructura compuesta por filas y columnas donde se guardan los datos de una entidad, como clientes, productos o usuarios.
3. ¿Qué es una Relación?
Es la conexión que existe entre dos o más tablas, creada mediante claves primarias y foráneas para asegurar la consistencia de la información.
4. ¿Qué representa una Columna?
Corresponde a una característica o campo de una entidad.
Ejemplo: nombre, edad, correo electrónico.
5. ¿Qué representa un Renglón?
Es un registro completo, es decir, toda la información de una sola entidad.
Ejemplo: los datos de un cliente en particular.
6. ¿Qué es un motor de base de datos relacional?
Es el programa que se encarga de crear, administrar y consultar una base de datos relacional, interpretando instrucciones SQL y asegurando seguridad, integridad y buen desempeño.
7. Motores de bases de datos relacionales más utilizados
MySQL
PostgreSQL
Microsoft SQL Server
Oracle Database
MariaDB
9. ¿Qué significa SQL?
Structured Query Language.
Es el lenguaje estándar que se usa para consultar, agregar, modificar y eliminar datos en bases de datos relacionales.
10. Elementos de un sistema de información basado en bases de datos relacionales
Base de datos: almacena la información.
Motor de base de datos: administra los datos.
Lenguaje SQL: permite interactuar con la base de datos.
Aplicación: sistema que utiliza la información.
Usuarios: personas que acceden al sistema.
Hardware: equipos y servidores.
Red: permite el acceso desde otros lugares.
